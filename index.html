Connect private canvas

The public Room shell stays on GitHub Pages. Notes, positions, and uploads save to the private repo NathanFowler/room-data — never as commits on the public site. IndexedDB is a cache in this browser, not the source of truth.

  1. Create a fine-grained PAT at github.com/settings/personal-access-tokens.
  2. Resource owner: you. Only repository: NathanFowler/room-data.
  3. Permissions: Contents — Read and write.
  4. Paste it here. Stored in this browser only (localStorage). Never committed, never asked for in chat.
